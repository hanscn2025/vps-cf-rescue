    常见问题

    为什么要关掉代理再测？

    测的是“你家网络 → Cloudflare”这一段。开着代理（包括 TUN/增强模式）测，量到的是代理线路，结果没有意义。测完把新节点导入后再打开代理即可。

    什么样的节点能用？

    必须是已经走 Cloudflare 的节点：域名开了橙色云，传输方式是 WebSocket、XHTTP、gRPC、HTTPUpgrade 之一，并且开了 TLS。VLESS + Reality、直连 TCP 的节点不能走 Cloudflare，换 IP 也没用。

    原理是什么？

    Cloudflare 的每个 IP 都能接入所有走 Cloudflare 的网站。客户端连到哪个 IP 都行，只要 SNI 和 Host 还是你的域名。本页在你的网络上测出连接最快的几个 IP，把它们写进节点的“地址”，SNI 和 Host 保持原来的域名。

    节点信息安全吗？

    解析和替换都在本页的 JavaScript 里完成，不会发给任何服务器。勾选“记住节点”时只存在你这个浏览器的本地存储里。唯一的网络请求是：检测网络、加载候选 IP、对候选 IP 测速，以及通过 Cloudflare DNS 查询你节点的域名是否开了橙色云。

    “耗时”和客户端里的延迟为什么不一样？

    这里测的是和 Cloudflare 建立连接的时间（大约两个来回），客户端测的是经过节点访问网站的完整时间，两者不能直接比较，只用来给 IP 排序。
